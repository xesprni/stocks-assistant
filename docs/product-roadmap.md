# 产品范围与维护方向

当前产品聚焦通用 AI 对话、行情跟踪、自选股和个人资产管理。

## 保留功能

- AI 对话：会话持久化、流式响应、工具调用、多 Agent 编排、追踪和来源引用。
- 行情：指数及个股报价、K 线、分时、资金流向、市场温度和常用技术指标。
- 公司列表：按市场、关键词和自选分组组合筛选，排序、搜索添加和分组管理。
- 公司页面：图表、财务报表、个股新闻和持仓信息。
- 持仓：本地持仓与现金记录、资产分布、盈亏及行情缺失时的成本回退。
- 知识库与长期记忆：文件管理、索引、检索和知识图谱。
- 工作台：定时任务、通知、技能、MCP、配置、用户及权限管理。

## 维护重点

保持移动端横竖屏布局完整；确保筛选、图表状态和用户数据隔离正确；通过前后端测试验证行情、自选、持仓、聊天和知识库的主要流程。
