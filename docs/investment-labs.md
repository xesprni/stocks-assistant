# Investment Labs

Investment Labs 将组合风险、估值模型和大中华市场研究放到同一套可审计工作流中。入口为前端 `/labs`，API 前缀为 `/api/v1/labs`。

## Portfolio Lab

- 汇总 US、A、H 三个本地持仓市场，支持自选 benchmark 和 30–1000 日历史窗口。
- 使用当前组合权重回放历史收益，计算模拟 TWR、年化波动、最大回撤、Beta、基准相关性和 HHI 集中度。
- 展示标的收益贡献、市场/上市地/币种暴露，以及来自当前 Thesis 的共用风险暴露。
- 支持 symbol、市场、币种和默认冲击的线性压力情景，以及目标权重再平衡差异。
- 用户提供完整的日期现金流后计算 money-weighted IRR；缺少正负现金流或无法找到有效根时明确返回空值。

当前权重回放不是基于完整交易账本重建的历史 TWR。跨币种金额也不会在缺少 FX 序列时强制换算；响应中的 `coverage`、`warnings` 和 `limitations` 必须与结果一同展示。

## 估值与同业实验室

- DCF：保存收入、FCF margin、增长、WACC、永续增长、股数、现金、债务和预测年限，输出企业价值、股权价值、每股价值、终值占比、逐年预测和敏感性矩阵。
- Reverse DCF：从目标价格反推隐含收入增长率。
- 相对估值：按同业中位倍数和目标指标计算隐含股权价值。
- 同业比较：从 Longbridge 公司与估值板块读取 PE、PB、PS 和市值字段；缺失值不插补，并保留来源和抓取时间。
- 模型按 `model_key + version` 保存，支持关联 Thesis Snapshot、证据 source ID、同业列表、修改原因和创建时间。
- 可把 DCF 每股价值转为价格复核提醒；提醒仅用于触发研究复核，不代表交易指令。

## 大中华市场专项

- 根据 `.HK`、`.SH`、`.SZ` 后缀和用户的中概股标记区分 HK、A、US-China 和其他市场。
- 读取 Longbridge 静态资料、公司、估值、公告、分红、评级与公司行动，并保留抓取错误和时间。
- 支持 A/H/ADR 对应标的估值对照。
- 输出披露语言、币种、时区、专项研究清单以及政策/监管、上市结构、币种、跨境资金、治理和跨市场差异等检查维度。

专项清单是研究框架，不替代交易所规则、法律或税务意见；涉及实时规则时仍应核对交易所和监管机构的最新资料。

## Agent

只读工具 `get_investment_labs` 支持：

- `portfolio`：运行组合风险和归因分析；
- `peers`：读取实时同业估值；
- `valuation_models`：读取已保存模型；
- `greater_china`：生成大中华标的专项上下文。
