# 后端重构交付记录

本文先保留首轮重构的历史验证，最新全栈边界重构记录位于文末。当前扩展入口以 [架构边界与扩展约定](architecture-boundaries.md) 为准。

## 编码与运行基线

- 最低 Python 版本升级至 3.12，运行依赖版本保持原锁定值。
- Ruff 统一 100 字符行宽、现代类型写法、导入及 `E4/E7/E9/F/I/UP/B/SIM` 规则。
- 13 个独立辅助模块纳入严格 mypy；检查范围集中在 `pyproject.toml`。
- `bash scripts/check_backend.sh` 执行静态检查、格式检查、类型检查、测试和部署脚本语法检查。
- 部署脚本通过 `PYTHON_BIN` 选择解释器，在源码切换前检查 Python 和既有虚拟环境。实际 VPS 未执行升级。

## 主要结构变化

| 领域 | 结果 |
| --- | --- |
| API / 配置 | 配置更新下沉至 configuration service，统一缓存失效；响应公开字段和脱敏字段显式映射 |
| Agent | 聊天和调度共用工厂，provider、Agent 和工具使用同一配置快照；同步/SSE 共用成功收尾 |
| 工具 / LLM | 显式工具工厂，参数和持仓输出去重，共享文件路径检查及 SSE 内容转换 |
| 执行与追踪 | 提取上下文处理和流式状态累积；追踪拆为持久化、事件记录、payload 清理 |
| 应用存储 | 配置、身份权限、登录会话、集成和旧数据迁移独立成仓储，原 AppStore 门面显式委托 |
| Research / Labs | SQL 下沉至领域仓储，保留独立数据库和事务；材料解析、保存与索引集中编排 |
| 领域辅助逻辑 | HTML 提取、记忆检索条件和结果转换、行情格式化、估值纯计算复用 |

兼容门面和测试增加了少量代码；格式化也展开了原有长行。精简体现在重复逻辑减少、职责集中和核心模块语句减少，不以物理行数作为验收指标。

## 已修复缺陷

- 上下文摘要静态方法错误保留 `self`，触发摘要时抛出异常。
- 文件工具使用字符串前缀检查路径，允许访问同名前缀兄弟目录；改为解析后的路径边界检查。
- Memory API 在规范化前校验用户路径，允许目录穿越；现按实际用户目录校验。
- 工作空间变更遗漏行情、知识库、会话和追踪等缓存失效。
- 有效配置缓存返回嵌套可变对象，调用方修改会污染后续读取；改为隔离副本。
- MCP manager 仅清缓存未关闭连接；现按用户维护，配置更新和退出时显式释放。
- 记忆整理队列会立即转移到线程池无界队列；现限制执行中和待执行任务总数，并可靠释放配额。

## 第二轮：全栈事务、执行与异步状态边界（2026-09-09）

相对于 `39e207c`，本轮完成以下分组：

- 领域事务与计算策略：卖出在写事务内校验和计算；行情配置明确个人/legacy 适配器；Portfolio 公开快照及估值回退策略；Labs 共享事务与纯计算器；研究材料按保存事务返回的版本落盘和索引。
- Agent 与运行时：配置和审计原子提交、带代次的配置/Provider 缓存、显式工具上下文、读取并行及写入屏障、分类错误恢复、统一结果元数据；资源租约保留执行快照，统一关闭调度任务、聊天工作线程、MCP 和 HTTP 连接。

本轮完整质量检查使用已安装的锁定环境运行 `UV_NO_SYNC=1 UV_OFFLINE=1 bash scripts/check_backend.sh`。普通同步尝试因当前环境不能解析 PyPI 域名未完成，运行依赖与锁文件未变更。
